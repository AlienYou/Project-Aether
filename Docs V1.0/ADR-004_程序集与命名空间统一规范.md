# ADR-004_程序集与命名空间统一规范

版本：v1.0

项目：Project Aether

状态：已采纳

日期：2026-07-13

---

# 1. 背景

在实现：

* Core
* Framework
* Config
* Resource

模块过程中发现：

部分文档采用：

```text
Game.Core
Game.Framework
Game.Config
Game.Resource
```

作为程序集名称。

而项目整体命名为：

```text
ProjectAether
```

导致：

程序集名称

与

命名空间

出现不统一问题。

---

# 2. 问题分析

例如：

程序集：

```text
Game.Resource
```

命名空间：

```csharp
ProjectAether.Resource
```

虽然技术上可行，

但会导致：

* asmdef识别困难
* 项目迁移困难
* 代码审查困难
* 多项目共存困难

---

# 3. 决策

Project Aether 全项目统一采用：

```text
ProjectAether.*
```

命名规范。

---

# 4. 程序集规范

统一格式：

```text
ProjectAether.模块名
```

---

示例：

```text
ProjectAether.Core

ProjectAether.Framework

ProjectAether.Config

ProjectAether.Resource

ProjectAether.UI

ProjectAether.Character

ProjectAether.Combat

ProjectAether.Network
```

---

对应 asmdef：

```text
ProjectAether.Core.asmdef

ProjectAether.Framework.asmdef

ProjectAether.Config.asmdef

ProjectAether.Resource.asmdef
```

---

# 5. 命名空间规范

命名空间与程序集保持一致。

---

示例：

```csharp
namespace ProjectAether.Core;
```

```csharp
namespace ProjectAether.Framework;
```

```csharp
namespace ProjectAether.Config;
```

```csharp
namespace ProjectAether.Resource;
```

---

禁止：

```csharp
namespace Game.Resource;
```

```csharp
namespace Game.Config;
```

---

# 6. 目录规范

目录：

```text
Assets/GameScripts

├── Core
├── Framework
├── Config
├── Resource
├── UI
├── Character
└── Combat
```

---

目录名称允许简化。

但：

程序集名称

与

命名空间

必须保持：

```text
ProjectAether.*
```

---
